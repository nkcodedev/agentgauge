# Dashboard assets

Store public README screenshots here. Do **not** commit images that contain API keys, secrets, customer data, or private URLs.

## Suggested files

| File | Content |
| --- | --- |
| `dashboard-overview.png` | Overview KPIs + charts |
| `dashboard-agents.png` | Agents table |
| `dashboard-traces.png` | Traces explorer |

## Capture guidance

1. Run the local stack (`pnpm dev`) with seed/demo telemetry.
2. Use a clean browser window (no developer tools overlay).
3. Prefer a desktop viewport (~1440px wide).
4. Redact or avoid the Settings/API Keys page if any secrets are visible.
5. Reference images from the root `README.md` Dashboard section once files exist.

Until screenshots are added, the root README describes where they will appear.
